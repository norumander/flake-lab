A case counts as flaky when it both passed and failed on the same build. Intervals are Wilson score intervals. Patterns in when a case fails are tested with Mann-Whitney and Fisher exact tests at p < 0.01; duration steps with Pettitt's test at p < 0.001 and a shift of at least 10%.

Runs that produced no result file are counted as lab errors, never as test failures.
